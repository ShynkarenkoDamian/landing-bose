\# Технічний опис сторінки `v2 Bose`



| Параметр | Результат перевірки |

|---|---|

| Обсяг | Перевірено всю сторінку: три версії лендінгу, три меню, бібліотеку елементів, схеми сітки, інформаційні блоки, hover-приклад і схеми зображень. |

| Джерела значень | Геометрія, властивості тексту, заливки, обводки, ефекти, Auto Layout, сітки, стильові прив’язки, Variables, налаштування експорту, видимі підписи й прототипні зв’язки. |

| Координати | Якщо не зазначено інше, `x` і `y` відраховуються від лівого верхнього кута відповідної версії лендінгу або меню. |

| Точність | Дробові значення наведено без округлення. Співвідношення сторін подано точними відношеннями. |

| Висоти секцій | Більшість секцій не має окремого обмежувального фрейма. Нижче відокремлено фактичний діапазон контенту від невизначеної висоти секційного контейнера. |

| Dev Mode | Анотації Dev Mode недоступні з поточним рівнем доступу. Їхній вміст — \*\*НЕ ВИЗНАЧЕНО\*\*; для читання потрібен доступ Dev Mode. |

| Контент | Назви шарів не використано як текст лендінгу. Демонстраційні заповнення допоміжних елементів не перенесено в контент сторінки. `Cursor / Mouse` виключено з опису інтерфейсу. |

| Зміни макета | Макет не змінено. |

\## 13. НЕ ВИЗНАЧЕНО



\### 13.1. Параметри, яких макет не встановлює



| Категорія | \*\*НЕ ВИЗНАЧЕНО\*\* |

| Адаптивність | Точні breakpoint-значення переходів між трьома версіями; поведінка на проміжних ширинах; ширини менші за 320 px і більші за 1260 px |

| Max-width | Явні max-width-властивості контейнерів; max-width для 320 і 744 px; поведінка зовнішніх полів після 1260 px |

| Висоти секцій | Розміри окремих семантичних контейнерів, оскільки більшість секцій не обгорнута в окремі фрейми |

| Hero | Чи має висота залежати від viewport; окремий градієнт і його stops; правила повторного кадрування поза трьома підготовленими версіями |

| Hover | Точні тригери, тривалість, easing, затримки, анімація появи номера й зміни бургера |
